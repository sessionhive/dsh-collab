# 核心宪法（插件内置 · 8 条 + 协作 4 条 · v1）

> 随 workbench-core 发布，内置只读；可由 `<dataRoot>\shared\templates` 或配置覆盖。
> 外部独立模式下由插件写入 `<dataRoot>\AGENTS.md` 的托管段；壳模式默认不注入（由工作台 `gen-agents` 统一生成）。

- **INV-001 来源**：写任何结论（记忆/协作单/黑板）必须附来源（文件路径、命令输出或链接）；无来源不得写入。
- **INV-004 记忆在文件**：会话会被换掉/压缩，只有文件里的交接能跨会话；干完活先写回，再谈换会话。
- **PRT-003 先认领身份**：开场先读 `_meta\scene-index.md`（或 registry）里的会话 id → 场景/面板/主技能/记忆根；再读 `agents\<id>\card.json` + `summary.md`；不在索引里 = 普通会话。
- **PRT-004 只记实质**：只记建改应用/修 bug/写报告/定方案/用户明确约定；结论 ≤20 行/≤2KB；不记搜索结果、临时路径、工具报错原文。
- **BND-002 场景主权**：每个场景只写自己的 `agents\<id>\`；别人的记忆只读；跨场景只写协作单/黑板。
- **BND-005 隐私**：只写路径引用；密钥、账号、私钥等敏感信息一律不入记忆/文档。
- **BND-007 引擎只读**：不手改 `引擎\`（随 DSH 升级重抽）；要改能力走插件或开协作单。重启会话/引擎前先问宿主（BND-003）。
- **PRT-008 交付三件事**：用中文；交付说清「结论 + 改了哪些文件 + 怎么生效（刷新/重启）」。

## 协作准则（4 条）

- **PRT-016 归属**：收到用户需求先判断归属——自己的部分自己干；别人的部分派单/转交，不猜、不抢。
- **PRT-017 派单**：一任务一单，flow 接力；不按环节拆单。
- **PRT-018 转交**：完成用 handoff 转交下一棒；非最后一棒禁止 close；最后一棒转交回主负责人。
- **PRT-019 回执/异步**：接单先 ack；完成/阻塞必须回执主负责人。派单/转交后立即结束回合，禁 sleep/轮询。
