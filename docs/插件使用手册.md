# 插件「工作台核心」使用手册（面向使用者）

> 适用版本：**0.1.0** · 数据根：`引擎数据\.dsh\`（外部安装为 `<dataRoot>`）
> 本手册只讲怎么用；规则细节见 `说明\插件-协作协议v2-契约.md`。

## 1. 安装/升级
1. 安装/升级 `dsh-workbench-core` 包到宿主插件目录（宿主会处理 profiles）。
2. 重启工作台加载新版本；设置页出现「需重启加载新版本」时说明运行副本仍旧。
3. `/plugin-info` 可看运行版本/磁盘版本、manifest sha、升级提示。

## 2. 会话与协作
- 设置页「会话协作」：新建/编辑会话（名称、职责、技能）；保存不打扰会话。
- 新建未选技能会自动创建 `skills/<id>/SKILL.md` 并绑定。
- 交接：旧会话改名「<名>（已交接 时间）」，新会话沿用原名；工作区按 会话cwd→场景cwd→defaultCwd→dataRoot 回退。
- 协作单：`wb_write(task)` 建单；`flow` 接力；`handoff` 转交；最后一棒 `close`。非最后一棒 close 会自动转交。
- 一任务一单：复合需求用 flow，不拆单；重复任务硬拒绝。
- `wb_write(task)` 不带 assignee 会按 card 名称/职责/技能返回 2~3 候选。

## 3. 工具速查
| 动作 | 说明 |
|---|---|
| `wb_read` | check/scene/order/board/search；`order` 返回 steps/current_owner/next/timeline/metrics |
| `wb_write` | note/progress/comment/task/submit/verify/reject/handoff/close/cancel/reopen；支持 `dryRun:true` 预览 |
| `wb_write(search)` | 记忆检索 query/scope/since/limit |
| 学习 | 看板「学习」卡；抽屉「顺利/卡住/有问题」一键反馈 |

## 4. 验收边界
- 只核：refs 可达、结论与任务一致、无未决项、close+交付。
- 默认不抽检；仅缺失/矛盾/高风险抽检 ≤3；禁止重跑 build/vet/test/黑盒/重编。
- close 前 refs 必须存在/可读/路径规范（拒绝 `..` 穿越/超 20MB）。

## 5. 记忆与索引
- 写入：`agents/<id>/memory/<日期>/note.md`、`note.detail.md`（单号文件不变）。
- `INDEX.md`：`## 日期` + `- HH:mm dhNNN · 类型 · 一句话（证据）`；≤120 行，超出按月折叠。
- 交接摘要含最近 3 条记忆（去重、含 detail）。

## 6. 单号与完成索引
- 单号 `dhNNN` 每日重置；跨日引用写 `YYYY-MM-DD/dhNNN`。
- `collab/done-index.md`：按日期分段，列 时间/单号/标题/负责人/状态/路径。

## 7. 看板
- 两栏：左会话表+在途单，右事件流+学习+黑板+规则。
- 会话/单可点开抽屉；flow 步骤条（✓/●/○）；事件按类型筛选；KPI 含返工率/单均时长/stale 率。

## 8. 学习闭环
- 自动采集 close/verify/reject/handoff/stale/violation/feedback 信号到 `_meta/learn/signals.jsonl`。
- 周报 `_meta/learn/weekly.md`；学习卡显示失败模式与自动调整，可「回退」。
- 自动应用仅插件默认（seed 已知坑/模板提醒等），每周 ≤3，绑定版本，大版本失效。

## 9. 健壮性
- 唤醒失败退避重试 2 次，仍失败写 `_meta/outbox.jsonl` 降级。
- 日志 `_meta/logs/plugin.log`（结构化，1MB 轮转；`config.debug` 控制 debug 级）。
- `config.lang`：`auto`（默认）/`zh`/`en`；文案在 `locale/*.json`。

## 10. 自检
- `/ops/selfcheck`：纯插件逐项（路由/dataRoot/config/index/版本/模板/技能/trash-logs/manifest）。
- 规则一致性：`node 工具\gen\gen-index.mjs --check` + `node 工具\宪法.mjs --check` + `node 工具\gen\check-handover.mjs`。
- 界面：`node 外壳\scripts\check-gui.mjs`。
